# Aviso de privacidade — modelo operacional

Este sistema trata dados de cadastro de clientes (nome, telefone, e-mail, observações e histórico de compras) em nome de cada loja contratante.

- A loja é responsável por informar a finalidade do cadastro e limitar o acesso aos funcionários necessários.
- Nummo e seus operadores técnicos atuam como operadores da plataforma, usando os dados somente para prestar, proteger e manter o serviço.
- Senhas nunca são exibidas e são armazenadas com hash forte.
- Dados de lojas diferentes são isolados por identificador de tenant.
- O administrador pode exportar os dados de um cliente e anonimizá-los, preservando somente registros comerciais necessários.
- Incidentes, solicitações de acesso, correção ou eliminação devem ser registrados pelo canal de suporte definido no contrato.

Antes da venda comercial, preencher razão social/CNPJ, contato de privacidade, prazo de retenção e canal oficial. Este arquivo é um modelo técnico e deve passar por revisão jurídica brasileira.
